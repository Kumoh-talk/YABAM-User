# YABAM-User
- 축제 주막 테이블오더의 사용자용 모바일 웹입니다. <br/>
- 사용자는 주막 목록을 확인하고, QR 코드로 테이블을 인증한 뒤 메뉴 조회, 장바구니 담기, 주문, 주문 현황 확인, 직원 호출을 진행할 수 있습니다.
